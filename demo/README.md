# 私享股池 · 前端 Demo（可点击原型）

> 股票辅助判断与交易参考的**内部使用**原型，小红书笔记风，仅供个人 + 几位朋友把玩。
> 纯静态前端，**无需后端、无需构建、无外部 CDN**，双击 `index.html` 即可在浏览器打开。

## 如何打开
- 直接双击 `index.html`（推荐用 Chrome / Edge / Safari）。
- 因为不依赖任何网络/CDN，断网也能正常打开。
- 手机预览：可把 `demo/` 目录整体拷到手机本地，用浏览器打开 `index.html`；或电脑开 DevTools 切到手机模式看移动端效果。

## 文件结构
| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构、顶部市场切换、底部 5 个 Tab 导航 |
| `styles.css` | 小红书风纯手写样式（暖色点缀 / 卡片圆角 / 移动端优先） |
| `mock-data.js` | 三大市场 mock 行情 / 信号 / 推荐 / 自选数据 |
| `app.js` | 页面切换、市场切换、标签筛选、加入自选、信号详情弹层 |

## 5 个页面
1. **行情总览**：市场 Tab 切换；三大指数卡片；涨跌家数分布条；今日异动卡片流。
2. **自选股监控**：触发信号摘要条；按「长线 / 短线观察」分组；点行看信号理由。
3. **买卖点信号**：五级信号列表 + 一句话人话理由；点开看理由清单（✅/⚠️）。
4. **个股推荐**：小红书种草卡片流；顶部标签筛选（#刚金叉 等）；可「加入自选」。
5. **市场筛选**：市场 / 行业 / 技术形态筛选；结果行含信号徽标，每行右侧有「+加入自选」按钮（点击变「已加入⭐」、可再次点击移出）；点行看理由弹层，弹层内也提供「加入自选」入口。

## 交互说明
- 底部导航切换 5 个页面；顶部「A股/港股/美股」切换全市场数据。
- 「加入自选」为前端内存状态，点一下变「已加入 ⭐」，刷新页面后重置（符合免持久化要求）。
- 所有数据为 mock，仅供演示，不构成任何投资建议。

- `node --check mock-data.js` ✅ 通过
