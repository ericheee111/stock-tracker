## 指标注册最小字段

每个指标应登记：metric_id、schema/version、中文显示名、经济含义、精确公式、输入单位、价格复权口径、时间频率、lookback、最少样本、warmup、缺失/异常规则、适用市场/证券类型、输出范围、计算时间、输入快照ID、实现位置、测试向量、引用来源与变更记录。

不允许同名不同义：例如趋势强度不是上涨概率，波动不是损失概率，历史胜率不是未来成功率，数据可用性不是模型置信度。跨周期/策略/市场的分数未经校准不可直接排序比较。

## 指标类别与默认使用规则

| 类别 | 合理用途 | 应避免 |
|---|---|---|
| 趋势/动量 | 描述方向和持续性，形成触发条件 | 多个高度相关指标重复叠加出虚高分 |
| 波动/ATR | 风险尺度、止损距离和横向标准化 | 把低波动解释为没有风险 |
| 量价/流动性 | 参与度、成交可行性、异常状态 | 将来源不同单位混合；把报价当成交 |
| 相对强弱/广度 | 同时间截面、同可比Universe排序 | 事后Universe或停牌遗漏带来选择偏差 |
| 估值/财务/事件 | 在披露可用时间之后提供条件 | 使用事后修订或今天才知道的事实回填过去 |
| 综合评分 | 规则诊断和可比cohort内排序 | 自动映射概率或越过硬风险约束 |
| 校准概率 | 指定标签/周期/市场下概率预测 | 样本不足仍给精确百分比 |
| 执行/结果 | 计划与事实对照、成本和归因 | synthetic/paper/manually claimed混入真实绩效 |

## 变更流程

1. 锁定现有公式与输出为baseline，建立固定输入向量。
2. 写出变更假设、适用cohort、预期改善指标、可能失效场景。
3. 对照正确性、时间一致性、缺失与极端输入；改变公式必须升级版本。
4. 进行时序样本外比较，保留全部试验与失败，不挑最后最好的测试集结果。
5. 分别报告预测质量、交易后果、费用敏感性、回撤/尾部风险、换手与稳定性。
6. 默认先影子比较，不自动晋级、不自动改变生产权重、不自动下单。

## 数值与时间

金额/价格/数量的表示依据现有领域合同；不得把bool作为数字或把空值补0。分母为0、warmup不足、缺字段、非法证券规则必须返回有类型的不可用/阻断状态。四舍五入在明确边界发生，展示层不能反向影响策略计算。

所有时间字段必须标明市场事件、接收、计算、持久化或独立可用时间。复权因子、财务修订、Universe与交易状态必须按当时可用版本使用。当地日期不是所有证券的完整Session规则，沿用版本化Calendar/Segment事实。

## 风险与排序

硬约束先于机会排序，但可观察数据与手工记账不被研究级证据门禁一并禁用。建议结果包含：recommended_action、trigger/invalidity、risk_constraints、opposing_evidence、data_status、computed_at、expires_when、strategy_version，而不是只有总分。

## 用户界面

每个分数提供“为什么是这个值”的可展开解释；每个概率显示标签/周期、有效样本与校准边界；每个收益或胜率显示证据模式、cohort、成本口径和as-of。缺失就是缺失，真实零就是零，不制造伪精度。
